# Ciberseguridad — Portfolio práctico

Bienvenido a mi repositorio de **Ciberseguridad**.

Soy **Lorenzo Resnik**, estudiante de Ingeniería Informática, y estoy desarrollando conocimientos de ciberseguridad mediante prácticas técnicas y laboratorios realizados en entornos Linux.

Este repositorio reúne evidencias de mi aprendizaje, mostrando no solo la teoría, sino también la **ejecución práctica, análisis, documentación y resolución de problemas**.

---

## 🎯 Sobre este repositorio

El objetivo es construir un registro progresivo de prácticas de ciberseguridad y seguridad informática.

A medida que avanzo en el curso, incorporo diferentes áreas:

- Análisis de tráfico de red.
- Seguridad en redes.
- Linux y administración básica del sistema.
- Reconocimiento y análisis de servicios.
- Wireshark.
- Nmap.
- VirtualBox y laboratorios virtualizados.
- Phishing y concientización sobre ingeniería social.
- Gestión segura de credenciales.
- KeePassXC.
- VeraCrypt y almacenamiento cifrado.
- VPN, HTTP y HTTPS.
- Buenas prácticas de seguridad en redes públicas.
- Documentación técnica utilizando Markdown y GitHub.

## 🧪 Prácticas realizadas

### 02 — Laboratorio seguro

Prácticas iniciales orientadas a la preparación de un entorno de laboratorio y conceptos básicos de seguridad informática.

📁 [02-checkpoint-laboratorio-seguro](./02-checkpoint-laboratorio-seguro)

### 03 — Análisis de tráfico

Prácticas de análisis de tráfico de red utilizando herramientas de captura y observación de paquetes.

El objetivo es aprender a identificar protocolos, comunicaciones y datos que pueden quedar expuestos durante una conexión.

📁 [03-checkpoint-analisis-trafico](./03-checkpoint-analisis-trafico)

### 04 — Phishing

Análisis de phishing y de los principales elementos utilizados en este tipo de ataques, junto con recomendaciones para identificar intentos de engaño.

📁 [04-pre-entrega-phishing](./04-pre-entrega-phishing)

### 05 — Bóveda y contenedor seguro

Implementación práctica de mecanismos para proteger credenciales y archivos.

Se trabajó con:

- **KeePassXC** para crear una bóveda local de credenciales.
- Generación de contraseñas aleatorias y robustas.
- **VeraCrypt** para crear un contenedor cifrado.
- Cifrado **AES**.
- Sistema de archivos **exFAT**.
- Montaje y desmontaje de volúmenes.
- Copia de seguridad del encabezado.

📁 [05-pre-entrega-boveda-contenedor](./05-pre-entrega-boveda-contenedor)

### 06 — Seguridad en redes Wi-Fi públicas

Práctica orientada al análisis de los riesgos de utilizar redes Wi-Fi públicas.

Se estudia la diferencia entre **HTTP y HTTPS**, la información que puede observarse durante una solicitud y el papel de una **VPN** para proteger el tráfico mediante cifrado y un túnel seguro.

📁 [06-pre-entrega-wifi-segura](./06-pre-entrega-wifi-segura)
